## Research applied before source changes

- Android's [Compose performance guidance](https://developer.android.com/develop/ui/compose/performance/bestpractices) recommends stable lazy-list keys, limiting recomposition from fast-changing state, and moving expensive sorting/calculation out of composables. Sundown keeps stable album/artist/song/playlist keys, precomputes sorted/library/playlist indexes off-main, and confines the 250 ms playhead updates to the timeline subtree.
- Android's [MediaStore guide](https://developer.android.com/training/data-storage/shared/media) recommends per-volume version and generation checks; a version change requires a full synchronization. Sundown retains incremental version/generation scans and now treats detached volumes as unavailable rather than deleted, retaining their last successful checkpoints.
- Android's [Media3 background-playback guide](https://developer.android.com/media/media3/session/background-playback) and the [Media3 session demo](https://github.com/androidx/media/tree/release/demos/session) support placing the player/session in a `MediaSessionService` and using session metadata for the system media notification. Sundown follows that native path and uses local artwork metadata; no hand-built notification or Notification Listener is added.
- The [Predictive Back guide](https://developer.android.com/develop/ui/compose/system/predictive-back) and [Compose inset guidance](https://developer.android.com/develop/ui/compose/system/insets) support gesture-progress-aware back handling and safe drawing around bars/cutouts. Sundown keeps back handling inside the active sheet, leaves root back to Android, and uses visibility-ignoring status insets for its immersive status strip plus navigation/IME insets for sheet content.
- Open-source comparisons: [LocalTracklist's artwork loader](https://github.com/quietswitch/LocalTracklist/blob/master/app/src/main/java/com/libreplayer/ui/components/Artwork.kt) uses a bounded bitmap LRU, `Dispatchers.IO`, platform thumbnail loading and cancellation checks; its [device scanner](https://github.com/quietswitch/LocalTracklist/blob/master/app/src/main/java/com/libreplayer/library/scanner/DeviceLibraryScanner.kt) models per-volume identity and unavailable sources; its [playback service](https://github.com/quietswitch/LocalTracklist/blob/master/app/src/main/java/com/libreplayer/media/service/PlaybackService.kt) uses `MediaSessionService`. These patterns informed bounded local decoding, per-volume deletion safety and the platform session path. [Auxio's MediaStore layer](https://github.com/OxygenCobalt/Auxio/blob/dev/musikr/src/main/java/org/oxycblt/musikr/fs/mediastore/MediaStore.kt) and [session holder](https://github.com/OxygenCobalt/Auxio/blob/dev/app/src/main/java/org/oxycblt/auxio/playback/service/MediaSessionHolder.kt) were inspected as a mature native-player comparison; its session uses `MediaSessionCompat`, so it is not treated as a direct Media3 template. No third-party code or dependencies were copied/added; Sundown keeps its existing bounded `ArtworkStore` instead of adding Coil or an online image stack.
- Android 13's [granular media-permission guidance](https://developer.android.com/about/versions/13/behavior-changes-13) requires `READ_MEDIA_AUDIO` for shared audio. Sundown requests that only on API 33+, uses legacy audio read permission only through API 32, and does not request image/video or notification permission.
